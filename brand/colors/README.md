# Paleta do Laravel Starter Kit

| Família | Base | Papel |
| --- | --- | --- |
| Petróleo | `#00161E` | estrutura, texto e superfícies escuras |
| Turquesa | `#2AD5BE` | base do sistema Promovaweb |
| Rosa | `#FC325B` | módulos, extensão e destaque |

No light mode, use acento textual `#BE123C`. No dark mode, use `#FDA4AF`.
A escala completa e os estados ficam em `palette.json`; os pares aprovados
ficam em `../accessibility.md`.
